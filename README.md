## The line

> Diagnosis: advanced procrastination. You booked 47 therapy sessions to avoid one conversation, and this is session 48. It auto-renews.

134 characters, one line. Three punchlines stacked on one deadpan chart-note: the patient booked 47 sessions to dodge a single conversation, this session is number 48 — the avoidance is happening right now — and it auto-renews, so the therapy itself has become the subscription he hides behind. Clinical voice throughout, twist at the end, and a mechanism no other entry in the field uses (the field is crowded with tab-hoarding, doomscrolling, people-pleasing, apologising to the chatbot and shower arguments; none of them turn therapy itself into the avoidance).

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, and prints it.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
